# 🎵 Video & Music Bot для Telegram

Бот, который:

- 🔎 **Находит музыку по названию или имени исполнителя.** Пишешь `Dior` или `Pop Smoke Dior`, бот показывает список из 10 треков с длительностью, кнопками **1–10** и **⬅️ ❌ ➡️** (до 30 результатов). Нажал номер, и сразу приходит MP3 320 kbps с обложкой, исполнителем и названием.
- 🔗 **Прислал ссылку, выбрал, что нужно:** 🎬 видео в HD, 🎵 только аудио MP3 или 🔍 найти музыку из видео (Shazam).
- 📥 **Скачивает видео из YouTube, Instagram и TikTok** в лучшем доступном качестве (до 1080p, H.264 + AAC, чтобы видео играло прямо в Telegram на любом телефоне, TikTok без водяного знака, карусели Instagram альбомом).
- 🎧 **Распознаёт музыку как Shazam.** Присылаешь видео, аудио, голосовое или кружочек, бот слушает несколько отрывков (середина, начало, конец), находит песню и сразу присылает её MP3.
- 🎵 Под каждым скачанным видео есть кнопка **«Скачать песню»**: бот распознаёт музыку из этого видео и присылает MP3.
- 🔥 **Чарты в меню:** «Топ недели» (то, что все шазамят и крутят в TikTok/Reels), топ Узбекистана и топ России. Источник: чарты Shazam, а если для страны чарта нет, свежие хиты с YouTube. Команда `/top`.
- ⚡ **Speed up** и 🌙 **Slowed + reverb** под каждым MP3: бот делает версию песни в один клик.
- ❤️ **Моя музыка:** кнопка «В избранное» под треком и личный плейлист (`/mymusic`).
- 💅 Хайповое оформление: реакции 👀 → 🔥 на сообщения, карточка Shazam с обложкой, кнопки «Поделиться» и «В группу», меню на клавиатуре.
- ⚡ Повторные запросы отдаются мгновенно: бот запоминает уже отправленные файлы.
- 🌐 Три языка: 🇺🇿 узбекский, 🇷🇺 русский, 🇬🇧 английский (выбирается по языку Telegram, смена через `/lang` или кнопку «🌐 Язык»).
- 👑 **Админ-панель** `/admin`: статистика (всего, новые и активные за сутки и неделю, кто заблокировал бота, языки), рассылка всем пользователям с предпросмотром и подтверждением, топ поисковых запросов, диагностика, список админов. Первый, кто отправит `/admin` свежему боту, становится владельцем; других админов можно добавить командой `/addadmin ID`.
- 👥 **Группы**: добавь бота в группу, и он сам скачивает видео по любой ссылке в чате.
- 🔎 **Инлайн-режим**: в любом чате пишешь `@бот название песни`, выбираешь трек, и MP3 появляется прямо там. Включается один раз в @BotFather: `/setinline` (и `/setinlinefeedback` → Enabled, чтобы трек грузился сам без нажатия ⏳).
- 📝 **Текст песни**: кнопка под каждым MP3 (LRCLIB, Genius, lyrics.ovh).
- 🎧 **8D** и 🔊 **Bass boost** под кнопкой «🎛 Эффекты и рингтон» у каждого MP3 (эффекты для голоса и звука; клонирования голосов реальных певцов нет).
- 🎤 **Минус** (песня без голоса): работает на обычном процессоре, убирает голос, записанный по центру стерео. Качество среднее: часть эха голоса может остаться.
- 🔔 **Рингтон**: бот сам находит самый громкий кусок (обычно припев) и присылает 30 секунд в двух файлах: `.m4r` для iPhone и `.mp3` для Android.
- ⭕ **Видео в кружок или голосовое**: кнопки под скачанным видео и под любым видео, которое прислали боту.
- 🎧 **Музыка по настроению** (меню или `/mood`): грустное, для машины, для зала, той, чилл, о любви.
- 📊 **«Мой 2026»** (меню или `/wrapped`): карточка с итогами года: сколько треков скачано, любимые исполнители и песни.
- 🎵 **Похожие треки**: кнопка под MP3 подбирает похожие песни (Deezer, без ключей).
- 🔔 **Подписка на артиста**: кнопка «Следить за артистом» под MP3. Бот раз в 6 часов проверяет новые релизы и сам пишет подписчикам (`/follows`: список и отписка).
- 📂 **Плейлисты**: «📂 В плейлист» под треком, меню «📂 Плейлисты» (`/playlists`). Плейлистом можно поделиться ссылкой, друг откроет его и сохранит себе.
- 🎬 **Клип для сторис**: 15 секунд припева, вертикальное видео 1080×1920 с обложкой, названием и строчкой из текста.
- 🎧 **Мини-приложение (плеер)**: кнопка «🎧 Плеер» слева от поля ввода и команда `/app`. Внутри: поиск, «❤️ Моё», плейлисты, чарты и плеер с перемоткой. Плеер окрашивается в цвет обложки, показывает текст песни строка за строкой (из LRCLIB), умеет ставить ❤️, таймер сна, очередь «Далее» и отправку трека в любой чат. HTTPS-адрес даёт бесплатный Cloudflare-туннель из docker-compose, бот сам узнаёт адрес и ставит его на кнопку. Свой домен можно указать в `.env`: `WEBAPP_URL=https://…`.
- 💾 **Своя база MP3**: каждый MP3, который присылают боту (с исполнителем и названием), сохраняется и первым выдаётся в поиске, Shazam и инлайн-режиме.

## Быстрый старт (Docker)

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Скопируйте настройки и впишите токен:
   ```bash
   cp .env.example .env
   nano .env        # BOT_TOKEN=...
   ```
3. Запустите:
   ```bash
   docker compose up -d --build
   docker compose logs -f bot
   ```

### Хорошее качество для длинных видео (рекомендуется)

Обычный Bot API разрешает боту отправлять файлы только до **50 МБ** и скачивать присланные пользователем файлы только до **20 МБ**. Короткие ролики из TikTok/Instagram помещаются всегда, а длинные видео с YouTube бот автоматически скачает в 720p / 480p, чтобы уложиться в лимит.

Чтобы снять ограничение (до **2 ГБ**), запустите свой Bot API сервер, он уже есть в `docker-compose.yml`:

1. Получите `api_id` и `api_hash` на https://my.telegram.org.
2. Добавьте в `.env`:
   ```
   TELEGRAM_API_ID=...
   TELEGRAM_API_HASH=...
   TELEGRAM_API_URL=http://telegram-bot-api:8081
   ```
3. Один раз выполните `logOut` для бота на облачном API: откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/logOut`.
4. `docker compose --profile local-api up -d --build`

### Если сервер заблокирован (Hetzner, AWS и т.п.)

YouTube, Instagram и TikTok часто блокируют IP дата-центров («Sign in to confirm you're not a bot»). В `docker-compose.yml` для этого уже всё включено, ничего настраивать не нужно:

- **Cloudflare WARP** (`warp`): если прямой запрос заблокирован, бот повторяет его через WARP и следующий час ходит на этот сайт сразу через него.
- **PO-токены для YouTube** (`pot-provider`): yt-dlp сам получает токены, которые YouTube требует от серверов.
- **Другие клиенты YouTube**: при «not a bot» yt-dlp пробует клиенты tv_simply, mweb, web_safari.
- **cobalt**: если YouTube блокирует сервер, видео и MP3 скачиваются через публичные серверы cobalt без регистрации (список с instances.cobalt.best; свои можно указать в `COBALT_INSTANCES`).
- **Invidious / Piped**: если и cobalt не помог, видео и аудио скачиваются через публичные серверы Invidious/Piped (список берётся автоматически; свои можно указать в `YT_ALT_INSTANCES`, например `https://inv.example.com,piped:https://pipedapi.example.com`).
- **MP3-каталог (hitmotop)** и **SoundCloud** как запасные источники MP3 (зеркало каталога можно задать в `HITMO_URL`).

Команда **`/diag`** в Telegram показывает, что работает с сервера: YouTube, SoundCloud, TikTok напрямую и через прокси, MP3-каталог и Invidious/Piped (если задан `ADMIN_IDS`, команда доступна только админам).

### Если YouTube всё равно блокирует сервер

IP дата-центров (Hetzner и др.) YouTube часто блокирует полностью. Тогда два варианта:

1. **Cookies запасного Google-аккаунта (бесплатно).** Экспортируйте `cookies.txt` (формат Netscape) расширением «Get cookies.txt LOCALLY» и просто **отправьте файл боту** из аккаунта админа. Бот сохранит его в `data/cookies.txt`, сразу проверит YouTube и ответит. `/cookies` показывает статус, `/cookies off` удаляет. Можно и по-старому: `COOKIES_FILE=/app/cookies.txt` в `.env`.
2. **Резидентный прокси (платно, без аккаунта).** Добавьте в `.env` строку `YT_PROXY_URL=http://логин:пароль@хост:порт`: он будет использоваться только для YouTube и первым.

TikTok, если yt-dlp не может его скачать, качается через tikwm.com (без водяного знака).

### Группы

Чтобы бот видел ссылки в группе, отключите ему Privacy Mode в @BotFather (`/setprivacy` → Disable) или сделайте его администратором группы.

## Запуск без Docker

Нужны Python 3.11+, `ffmpeg` и [deno](https://deno.com) (yt-dlp использует его для YouTube).

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN
python -m bot
```

## Обслуживание

Обновление бота (одной командой):

```bash
cd ~/video-bot && git pull && docker compose up -d --build
```

- **Регулярно обновляйте yt-dlp.** YouTube, Instagram и TikTok часто меняют сайты, и новые версии yt-dlp это чинят: `docker compose build --pull --no-cache && docker compose up -d` (или `pip install -U "yt-dlp[default]"`).
- Временные файлы удаляются автоматически.

## Как устроено

```
bot/
  __main__.py           запуск, роутеры, фоновая очистка
  handlers/start.py     /start /help /lang /stats
  handlers/links.py     ссылка → выбор: видео / аудио / Shazam
  handlers/recognize.py видео/аудио/голос → Shazam → MP3
  handlers/search.py    текст → список 1–10 → MP3
  services/downloader.py yt-dlp: поиск, MP3, видео
  services/recognizer.py распознавание (shazamio)
  services/media.py     ffmpeg/ffprobe
  db.py                 SQLite: пользователи, кэш file_id, поиски, статистика
  texts.py              тексты RU / UZ
```

Тесты (без интернета, с настоящими ffmpeg и yt-dlp на локальном сервере):

```bash
pip install -r requirements-dev.txt
pytest
```
